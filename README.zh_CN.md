# PubChem 批量数据获取客户端

一个用于批量查询并检索 PubChem 化学数据的命令行客户端。针对 Windows 进行了优化，具备系统代理检测、API 合规限速、双轨指数退避重试、本地二级缓存以及异常中断保护机制，并确保输出的数据行与输入文件对齐。

---

## 核心特性

* **自动类型推断**
  客户端会自动使用正则表达式识别输入标识符的类型，并路由至相应的查询接口：
  - 纯数字 -> `cid`
  - 以 `InChI=` 开头 -> `inchi`
  - 27 位双横线格式（例如 `XXXXX-XXXXX-X`） -> `inchikey`
  - 包含常见化学元素的大写字母及配对符号且不含禁用字母 -> `smiles`
  - 其他情况（小写全字母、俗名或商品名） -> `name`
  针对小写纯字母俗名（如 `aspirin`）与简易 SMILES 冲突的问题进行了安全分流优化，避免误判。

* **Excel 多工作表处理**
  支持包含多个工作表（Sheets）的 Excel 文件：
  - **全局去重查询**：在全局层面汇总所有工作表中的标识符并进行去重，只对缓存未命中的唯一值发起网络请求，从而减少网络请求次数。
  - **保持原始结构**：顺序处理每个工作表，并按原有的工作表名称、行数和物理顺序写回到同一个输出 Excel 文件中。
  - **CSV 格式合并**：如果选择导出为 CSV 格式，会将所有工作表的数据进行垂直合并。

* **自动重试与代理支持**
  - **系统代理检测**：启动时自动获取 Windows 系统注册表中的全局网络代理配置（包括 Clash 或系统 HTTP/HTTPS 代理），并将其应用到当前 Python 进程。
  - **SSL 补丁**：针对 Python 3.13 下本地代理隧道可能导致的 `ssl.SSLEOFError` 握手终止故障，自动打上全局 SSL 补丁，强制创建不校验的 SSL 协议上下文，确保代理连接顺畅。
  - **网络连接重试**：当遇到网络连接超时、连接重置或 SSL 握手中断等底层错误时，使用带有随机抖动的指数退避机制进行重试。
  - **HTTP 错误重试**：当收到 503（服务器繁忙）或 504（网关超时）等服务器超载错误时，重试最多 5 次。若仍失败，则安全降级为未找到（404）。
  - **限速合规限制**：在每次向 PubChem 发送的网络请求之间引入 0.25 秒的延迟，以严格遵守每秒不超过 5 次请求的官方合规要求。

* **本地缓存**
  客户端将数据持久化在本地的 `cache/pubchem_cache.json` 中。
  - 以标准的 `InChIKey`（27 位哈希）作为主键存储化合物详情。
  - 使用二级冗余索引（`query_index`）将小写的别名（包括俗名、CID、SMILES、InChI 以及 IUPAC 名称）映射到唯一的 `InChIKey`。这实现了同一化合物不同别名的本地缓存快速命中。
  - **空值负向缓存**：对于未匹配到或查询失败的输入，在本地缓存中标记为 `"404 Not Found"`，避免重复发送无效请求。
  - **原子级写入**：写入缓存时使用 `.tmp` 临时文件，完成后重命名替换原始缓存文件，防止因突然断电导致 JSON 文件损坏。

* **行级严格对齐与中断保护**
  - 读取输入文件的第一列并提取标识符（支持自动检测并跳过表头）。
  - 确保输出文件的行数和物理顺序与输入文件保持一致。
  - 当某一行数据在 PubChem 中无匹配或遭遇 404 时，指定的输出字段列统一填充为 `"404 Not Found"`，避免行错位。
  - **中断保护**：在用户按下 `Ctrl+C` 强行中断时，系统会捕获键盘信号，将当前已经成功获取并缓存的部分数据写入输出文件，未完成的行填充 `"404 Not Found"` 后退出。

* **中文日志与报错输出**
  错误消息、命令行参数验证警告以及日志信息使用中文输出，便于本地调试。

* **控制台 UI 交互**
  使用 `rich` 库在控制台中显示 Banner 标题、进度条以及运行结束后的数据汇总表格。

## 安装指南

需要 Python 3.8 或更高版本。要安装依赖，运行以下命令：

```bash
pip install -r requirements.txt
```

---

## 运行与命令行参数

您可以通过以下命令运行主程序：

```bash
python app.py --input <输入路径> [--scope <要导出的字段>] [--output <输出路径>] [--batch <批量大小>] [--header <表头策略>]
```

### 参数详解
| 参数名 | 默认值 | 描述 (错误消息以中文输出) |
| :--- | :--- | :--- |
| `--input` | **必填** | 输入文件的相对或绝对路径，支持 `.csv`、`.xlsx` 和 `.xls` 格式。 |
| `--scope` | `cid name smiles weight` | 需要导出的化合物属性字段列表（空格分隔），可用值见下方映射表。 |
| `--output` | `output.csv` | 输出文件的路径。文件扩展名决定输出格式（.csv 或 .xlsx）。 |
| `--batch` | `100` | 批量向网络发起请求的分包大小（仅针对纯数字 CID 生效）。 |
| `--header` | `auto` | 表头检测策略：`auto`（自动检测首行是否为表头）、`yes`（强制第一行为表头并跳过）、`no`（无表头，第一行即是数据）。 |

## 使用示例

### 1. 默认运行
使用默认设置运行（输出到项目目录下的 `output.csv`）：
```bash
python app.py --input my_compounds.xlsx
```

### 2. 自定义参数运行
顺序导出所有工作表的指定属性到 Excel，并设置批量大小为 50：
```bash
python app.py --input dataset.xlsx --scope cid name smiles weight formula xlogp tpsa --output result.xlsx --batch 50
```

## 项目模块结构

核心代码位于 `lib/` 目录下：

```
pubchem-scrabber/
│
├── app.py                      # 应用程序入口、控制台交互与异常拦截
├── requirements.txt            # 第三方依赖列表
├── README.md                   # 英文版项目使用指南
├── README.zh_CN.md             # 中文版项目使用指南 (本文件)
│
├── lib/                        # 核心服务逻辑
│   ├── cli_parser.py           # 参数解析、CSV/Excel 加载与表头检测
│   ├── network_engine.py       # 代理嗅探、SSL 补丁与指数重试
│   ├── cache_manager.py        # 二级多向反向缓存与原子级写入
│   └── batch_dispatcher.py     # 整合调度、CID 批量分流获取与行对齐
│
└── tests/                      # 单元测试文件包
    ├── test_cli_parser.py
    ├── test_network_engine.py
    ├── test_cache_manager.py
    └── test_batch_dispatcher.py
```
